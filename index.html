openpathogen Open-source, privacy-preserving and zero-install pathogen profiling in the web browser
Learn GitHub About

openpathogen is a free, open-source platform that screens FASTQ reads for antimicrobial resistance (AMR) and virulence genes using the KMA aligner compiled to WebAssembly. It runs entirely in your own browser and does not need any installation or account creation, and your sequence data never leaves your computer!
