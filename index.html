Antimicrobial resistance & virulence gene detection

Openpathogen is an open source platform that screens sequencing reads against pre-indexed AMR and virulence gene databases. It runs entirely client-side, requires no installation, no accounts and no data upload.

Quality control

Trims adapters and filters low-quality reads before alignment. Recommended.

Defaults: adapter trimming with auto-detection · quality filtering (min Phred 15, max 40% low-quality bases, max 5 Ns) · length filtering (min 15 bp) · poly-G trimming automatic · base correction off. The values below are fastp's defaults — turn any group off to pass reads through unfiltered.

Blank = auto: paired runs get fastp's per-run adapter detection, single-end uses the Illumina TruSeq default shown. Enter 5–100 IUPAC bases (e.g. a Nextera or custom index) to force your own — explicit sequences override auto-detection.

A read is dropped if more than the given % of bases fall below the Phred score, or it has more than the N limit.

Statistics and trimming cover your entire sample — the same trimmed reads the databases are run against. The precise fastp command for your settings is printed in the Logs and stored in both reports.

Nanopore reads: fastp is Illumina-oriented, so openpathogen runs it for statistics only — reads pass through untrimmed and unfiltered, and the databases see every read.
